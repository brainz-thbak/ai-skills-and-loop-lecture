| 실행하지 않은 검사를 실행했다고 보고하지 않는가 | ☐ |
| 같은 실패가 이어질 때 멈추는 조건이 있는가 | ☐ |
| 스킬을 바꾼 뒤 여러 과제와 보류 과제로 다시 평가했는가 | ☐ |
| 매번 지켜야 할 검사가 스킬에만 적혀 있지 않은가 | ☐ |
